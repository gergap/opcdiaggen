# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately by emailing
`gerhard.gappmeier@ascolab.com`. Include:

- A description of the vulnerability and its potential impact
- Steps or a minimal example for reproducing the issue
- The affected version or commit
- Any suggested mitigation, if available

Do not disclose the issue publicly until a fix or coordinated disclosure plan
has been agreed upon.

## Support Status

This project is provided as open-source software. There are no guaranteed
response times, supported versions, or security update commitments.
